# 🎓 EduManage - School Management System

EduManage is a lightweight, modular School Management System designed to streamline administrative, academic, and financial operations in educational institutions. Built with modern PHP (PDO), MySQL, and Bootstrap 5, it features role-based access control and a responsive dashboard interface.

---

## ✨ Key Features

- 🔐 **Role-Based Authentication:** Secure BCRYPT-encrypted logins for Administrators, Teachers, and Students.
- 👨‍🎓 **Student & Faculty Registries:** Manage student enrollments, class assignments, and teacher profiles with automatic account creation.
- 📅 **Attendance & Timetable Matrix:** Track daily student attendance and construct dynamic weekly class schedules.
- 📊 **Exams & Grade Book:** Configure assessment terms, record marks, and view report cards.
- 💳 **Financial Ledger:** Track student fee structures, record partial/full payments, and review outstanding dues.
- 📚 **Library Vault:** Manage book inventories and monitor loan circulation status (Issued, Returned, Overdue).

---

## 🛠️ Tech Stack

- **Backend:** PHP 8.x (PDO Object-Oriented Database Layer)
- **Database:** MySQL / MariaDB
- **Frontend:** Bootstrap 5, FontAwesome 6, HTML5, CSS3, JavaScript (ES6)
- **Environment:** XAMPP / LAMP (Apache)
